# CCLW

Static first version of Costa Creus Lab Works.

## Local preview
Open `index.html` directly, or serve the folder with any static server.

## Cloudflare Pages
- Framework preset: None
- Build command: leave empty
- Build output directory: /
- Custom domain: cclabworks.dev

Recommended flow:
1. Create a GitHub repository named `cclw`
2. Upload these files
3. In Cloudflare: Workers & Pages → Create → Pages → Connect to Git
4. Select the repository
5. Deploy
6. Add `cclabworks.dev` as Custom Domain
